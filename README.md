# Learning Mentor (working title)

A personal AI learning mentor plugin for Claude: it keeps a local, human-readable model of what
the learner knows, plans learning paths, schedules reviews, and teaches Socratically without
writing the learner's solutions for them.

> **Status: Phase 1 — Research & Feasibility.** No code yet.
> This folder is incubated inside this repository and is planned to move to its own public
> repository (`git subtree split --prefix=learning-mentor`) before the first release.
