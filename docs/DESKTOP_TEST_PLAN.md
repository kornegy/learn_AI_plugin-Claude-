# Проверка в Claude Desktop перед релизом 1.0.0

Цель: проверить вживую то, что нельзя проверить из облака (спайк S2):
- как плагин работает в Cowork;
- что делает чат в приложении;
- как работает вкладка Code в Claude Desktop.

Время: 30–40 минут.

Результаты впишите в колонку «Результат»: ✅ работает, ❌ не работает, ⚠️ работает частично.
В «Заметке» коротко опишите, что видели. На ошибках делайте скриншот.
